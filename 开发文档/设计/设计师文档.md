# 设计师文档

最后更新：2026-08-14

本文件面向设计师，记录当前可读、可编辑的卡牌数值和规则说明。当前权威数据源已经迁移为 `游戏工程/data/cards.json`；本文件是由数值调校工具同步生成的设计师可读快照。

## 数据源与工具

- 权威卡牌数据：`游戏工程/data/cards.json`。
- Godot 读取入口：`游戏工程/scripts/v01/card_catalog.gd`，该脚本只负责读取 JSON 并把颜色等网页友好字段转换为 Godot 可用值。
- 设计师工具：`tools/balance_studio/`。启动方式见 `tools/balance_studio/README.md`。
- 协作者修改卡牌数值时，应优先使用工具或直接修改 JSON；不要再把 `card_catalog.gd` 当作数值表编辑。
- 工具保存时会同步刷新本文件；若手动改 JSON，也应运行工具保存一次或手动同步本文档。

## 全局单位

- 地图长边：100 个逻辑单位。
- 生物实战半径倍率：2；生物实战半径 = JSON 中的 `radius` × 2。
- 法术范围半径不乘生物半径倍率。
- 费用自然回复：每秒 0.5 点。
- 费用上限：10 点。
- 基地生命：300 点。

## 字段说明

| 字段 | 显示名 | 单位 | 适用 | 说明 |
| --- | --- | --- | --- | --- |
| cost | 费用 | 点法力 | 全部卡牌 | 部署单位或施放法术时一次性消耗。当前费用上限为 10 点。 |
| count | 生成数量 | 个单位 | 生物 | 每次使用该生物卡时生成的单位数量。 |
| hp | 生命 | 点 | 生物 | 单个单位的最大生命值，不是整张卡的总生命值。整卡总生命 = hp * count。 |
| damage | 攻击力/法术伤害 | 点 | 全部卡牌 | 生物为每次普攻伤害；法术为对单位伤害。 |
| base_damage | 基地伤害 | 点 | 法术 | 法术命中基地时造成的伤害。生物攻击基地仍使用 damage。 |
| attack_cooldown | 攻击间隔 | 秒/次 | 生物 | 越小攻击越快。单体 DPS = damage / attack_cooldown。 |
| range | 射程 | 逻辑单位 | 生物 | 地图长边为 100 个逻辑单位；速度和距离都使用该尺度。 |
| speed | 移动速度 | 逻辑单位/秒 | 生物 | 速度 1 表示每秒移动 1 个逻辑单位。 |
| radius | 半径 | 逻辑单位 | 生物和法术 | 生物这里填写基础半径，实战碰撞/表现半径 = radius * unit_radius_scale；法术范围不乘倍率。 |
| aoe_radius | 范围伤害半径 | 逻辑单位 | 生物攻击或进化效果 | 攻击落点或光环效果的范围伤害半径。 |
| aura_interval | 光环间隔 | 秒/次 | 进化生物 | 光环触发频率。光环 DPS = aura_damage / aura_interval。 |
| aura_radius | 光环半径 | 逻辑单位 | 进化生物 | 以单位当前位置为中心的周期范围效果半径。 |
| aura_damage | 光环伤害 | 点 | 进化生物 | 每次光环触发时造成的伤害。 |
| multi_target_count | 同时攻击目标数 | 个目标 | 进化生物 | 用于估算理想多目标 DPS；实际收益取决于可命中的敌人数量。 |
| spell_mode | 法术模式 | 枚举 | 法术 | single 为范围内最近单体，area 为范围伤害，line 为路径伤害。 |
| projectile_travel_time | 弹道飞行时间 | 秒 | 带弹道的法术 | 大于 0 时从施法方基地飞向目标点，并在抵达后结算法术；0 或未设置时即时结算。 |
| ai_deckable | Bot 可携带 | 布尔值 | 可携带卡 | 默认为 true；显式设为 false 时，Bot 的随机与固定牌组入口都会过滤该卡。 |
| play_cooldown | 出牌冷却 | 秒 | 有内置冷却的卡牌 | 成功使用后，同一阵营在倒计时结束前不能再次使用同一基础卡；进化前后共享基础卡 id 与冷却。 |
| max_mana_refund | 单次施放最大回费 | 点法力 | 回费区域法术 | 每个独立施放区域累计能实际加入法力条的费用上限；满费时的溢出不计入累计。 |

## 计算口径

- 生物单体 DPS = `damage / attack_cooldown`。
- 生物整卡 DPS = `单体 DPS * count`；若进化后有 `multi_target_count`，工具会额外估算理想多目标 DPS。
- 生物总生命 = `hp * count`。
- 每费效率 = 对应指标 / `cost`。
- 从 0 费等待时间 = `cost / mana_per_second`。
- 法术覆盖面积 = `π * radius²`。
- 进化后指标按 `evolution.overrides` 覆盖基础卡字段后半自动计算。

## 当前卡牌说明

### 星屑群

- 用途：低费多数量，测试场面铺开速度。
- 任务：本局中打出过三次星屑群。
- 进化：星屑漂流，数量变为 6，其余效果属性不变。

### 盾卫

- 用途：中低费承伤单位，测试抗线价值。
- 任务：当前血量低于 2/3。
- 进化：坚盾护卫，生命值翻倍，其余效果属性不变。

### 旋刃兵

- 用途：近战范围伤害，测试反杂兵能力。
- 任务：所有旋刃兵在本局中总共杀死超过 12 个敌人。
- 进化：轮刃兵，攻击间隔减少到 1.4 秒，射程提升到 2.5。

### 连弩手

- 用途：高频低伤远程，测试持续输出读秒。
- 任务：3 秒钟内使用 3 个连弩手。
- 进化：漫游弓手，一次攻击同时攻击两个敌对目标。

### 秘火手

- 用途：慢频高伤远程，测试爆发换线。
- 任务：一名秘火手击杀 3 名敌人。
- 进化：投火手，攻击落点附带半径为 2 的 AOE。

### 奥术巨像

- 用途：慢速高血量，只盯基地，测试推进压力。
- 任务：拥有 10 点法力。
- 进化：奥能巨像，基础半径变为 2；每 0.6 秒对 2.1 范围内造成 6 点 AOE 伤害。

### 裂魂矢

- 进化：裂天矢，费用变为 5；改为即时路径法术，不再保留 1 秒弹道；对己方基地到目标点路径上所有单位和基地造成伤害，己方基地也会被路径命中。

## 任务与进化规则

- 当前 16 张可携带卡都有任务和进化；3 个衍生单位不可编入牌组。
- 每张卡默认 1 个任务。
- V0.2 暂时不做局外任务配置部分。
- V0.2 进化先做 1 层。
- 任务进度仅在局内生效，不跨局保留。
- 任务完成后自动且不可避地进化到对应下一形态。
- 任务完成后只影响该卡后续使用；场上已经打出的单位保持生成时属性。
- 原型 UI：对局底部卡牌栏显示任务进度和“已进化”；结算统计显示双方任务完成数和进化数。
