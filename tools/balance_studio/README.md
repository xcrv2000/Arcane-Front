# 奥术前线数值调校台

本工具是 `开发文档/设计/设计师文档.md` 的可视化拓展，用于查看、编辑和保存当前卡牌数值与携带状态。

## 数据源

- 权威数据源已经迁移到 `游戏工程/data/cards.json`。
- Godot 入口 `游戏工程/scripts/v01/card_catalog.gd` 现在只负责读取 JSON，并把网页友好的颜色字段转换为 Godot 的 `Color`。
- `开发文档/设计/设计师文档.md` 是设计师可读快照，不再是权威数值源。
- 不要再把 `card_catalog.gd` 当作手写数值表维护。

## 启动

### 直接双击打开

设计师可以直接双击打开：

```text
tools\balance_studio\index.html
```

这种方式不需要先启动本地服务。页面会自动读取同目录的 `cards_snapshot.js` 离线快照，可以查看、编辑和计算 DPS 等指标。由于浏览器安全限制，`file://` 页面不能无确认地直接改写仓库里的 `游戏工程/data/cards.json`，所以右上角按钮会显示为“导出 JSON”。

导出的 `cards.json` 需要手动替换：

```text
游戏工程\data\cards.json
```

如果浏览器支持文件保存选择器，也可以在导出时直接选择覆盖这个文件。

### 服务模式

如果希望点击“保存”后自动写回权威 JSON，并同步刷新 `开发文档/设计/设计师文档.md` 与离线快照，推荐双击运行：

```text
tools\balance_studio\start_balance_studio.bat
```

脚本会启动本地服务，并用默认浏览器打开正确地址。

命令行方式：在仓库根目录运行：

```powershell
python tools\balance_studio\server.py --open
```

如果不使用 `--open`，则手动打开终端打印的地址，例如：

```text
http://127.0.0.1:8765
```

如果 8765 被占用，服务会自动尝试后续端口，并在终端打印实际 URL。

直接双击 `index.html` 时会优先进离线快照模式，不会自动探测本地端口，以避免浏览器控制台出现连接失败红字。需要服务模式时，请使用 `start_balance_studio.bat` 或直接打开终端打印的 `http://127.0.0.1:端口` 地址。

## 保存行为

点击网页右上角“保存”会同时写入：

- `游戏工程/data/cards.json`
- `开发文档/设计/设计师文档.md`

保存前工具会做基础结构校验，包括 id 重复、缺少必要字段、类型错误和负数费用等。

卡牌编辑区的“允许携带（关闭即禁用）”默认开启；关闭并保存后会写入 `deckable=false`。该卡仍保留在图鉴与运行时目录，但会从玩家牌组仓库、牌组存档有效集合和 Bot 卡池中排除。

直接双击 `index.html` 时，右上角按钮会变成“导出 JSON”：它只导出文件，不会自动同步 `开发文档/设计/设计师文档.md`。需要完整同步时，请使用服务模式保存一次。

## 当前 v0 指标

- 生物：单体 DPS、整卡 DPS、总生命、每费 DPS、每费生命、从 0 费等待时间。
- 法术：伤害/费、基地伤害/费、范围半径、覆盖面积、从 0 费等待时间。
- 进化：按 `evolution.overrides` 半自动估算进化后指标变化。
- 离群提示：根据同类卡的每费效率均值提示明显偏高项。
